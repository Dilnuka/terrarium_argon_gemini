# Verdant Glass — Interactive Terrarium Studio

An interactive botanical terrarium builder made with Gemini Argon.

Open the live site: **[GitHub Pages](https://dilnuka.github.io/terrarium_argon_gemini/)**

## Features

- Vessel, substrate, flora, and decor catalog
- Drag, scale, rotate, and layer SVG elements
- Ecosystem health scoring (humidity, light, plant guilds)
- Day/night ambiance, misting, fairy lights, and fireflies
- Presets: Mossy Zen, Desert Sun, Fairy Cove
- PNG snapshot export

## Run locally

Open `index.html` in a browser, or:

```bash
npx serve .
```
